# 🦅 Legends Street Workout

> **Forjando atletas, comunidad y disciplina desde 2019.**

Plataforma oficial del club deportivo **Legends Street Workout**, fundado en la comuna de **Lo Prado, Santiago de Chile**. Nuestro símbolo es el **fénix**, representando la resiliencia, la fuerza comunitaria y la capacidad de superarse y renacer más fuerte en cada entrenamiento de calistenia.

---

## ⚡ Inicio Rápido

Para poner en marcha el proyecto localmente, solo necesitas ejecutar dos comandos:

### 1. Instalar dependencias
```bash
npm install
```

### 2. Iniciar el servidor de desarrollo
```bash
ng serve
```

Una vez iniciado, abre tu navegador en:
```
http://localhost:4200/
```

## 🏆 Sobre SOC (Space Of Competitions)
**SOC (Space Of Competitions)** es la plataforma y circuito competitivo oficial asociado a Legends Street Workout. Se encarga de gestionar el calendario de torneos, estructurar las normativas de evaluación, auditar los jurados y administrar el proceso de inscripciones y pasarela de pagos para atletas de calistenia y street workout a nivel nacional e internacional.
